# ADK--Agents

1. Simple greeting Agent 

Greetings in various languages and even non-greeting inputs like questions, to show that the agent strictly follows its instructions to only respond with greetings. The agent successfully greets users in Spanish when they say "Hola," in French when they say "Bonjour," and in German when they say "Guten Tag," and it even responds with just a greeting when someone asks a question like "What time is it?"
